# Dataset provenance

Large raw graph datasets should be downloaded from their public sources rather than committed to GitHub.

For each dataset, the final artifact will record:
- paper abbreviation and full dataset name;
- source URL;
- exact downloaded filename/version;
- SHA-256 checksum;
- preprocessing command;
- final graph format;
- final vertex/edge counts.

Canonical paper order:

`Gn, Ep, Sl, St, No, Be, Go, Yo, Wt, Li, CTR, USA, IT, SK, Fr`
